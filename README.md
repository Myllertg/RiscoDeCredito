# Análise de Risco de Crédito | Machine Learning

## Sobre o projeto

Este projeto tem como objetivo desenvolver um modelo de Machine Learning capaz de identificar clientes com maior risco de inadimplência, contribuindo para uma tomada de decisão mais eficiente na concessão de crédito.

Utilizando a base de dados **German Credit Risk**, foi desenvolvido um processo completo de análise de dados, desde a exploração e preparação das informações até o treinamento, comparação e avaliação de modelos preditivos.

Além da capacidade de classificação, o projeto busca demonstrar como as previsões podem apoiar decisões de negócio, permitindo identificar potenciais clientes inadimplentes e estimar os valores de crédito associados a esses riscos.

## Etapas do projeto

- **Análise Exploratória de Dados (EDA):** investigação das características dos clientes, distribuição das classes e identificação de padrões associados ao risco de crédito.
- **Preparação dos dados:** tratamento das variáveis, codificação de atributos categóricos e organização da base para modelagem.
- **Modelagem preditiva:** treinamento e comparação de diferentes algoritmos de Machine Learning.
- **Avaliação dos modelos:** análise de métricas como Precision, Recall, F1-Score, ROC-AUC e Average Precision.
- **Otimização do Threshold:** definição de um limiar de classificação adequado ao objetivo de identificação de clientes com alto risco.
- **Análise de impacto financeiro:** avaliação dos valores de crédito associados aos clientes classificados como potenciais inadimplentes.
- **Aplicação interativa:** desenvolvimento de uma interface com Streamlit para utilização do modelo e realização de previsões.

## Objetivo de negócio

Demonstrar como a Ciência de Dados e o Machine Learning podem ser aplicados à gestão de risco de crédito, transformando dados históricos em informações relevantes para apoiar decisões de concessão de crédito, prevenção de inadimplência e redução de potenciais perdas financeiras.
